# Ермек Токтаров — философский сайт на Jekyll

Jekyll-сайт для GitHub Pages в визуальной системе «Философия для жизни». Основная навигация: **Maqala / Kerek / Monocast / CV**.

## Логика разделов

### Maqala
Главный письменный раздел. Сюда идут все полноценные тексты: философские эссе, разборы, мысленные эксперименты, главы и заметки, которые имеют самостоятельный тезис. Технически это стандартная папка Jekyll `_posts`.

### Kerek
Не второй блог. Это библиотека **полезных материалов**, к которым читатель может возвращаться: карты вопросов, схемы аргументов, мысленные эксперименты, списки чтения, конспекты и философские инструменты. Технически это коллекция `_kerek`.

Если со временем окажется, что таких материалов мало, Kerek можно убрать из верхнего меню без потери контента и оставить все тексты в Maqala. На старте раздел имеет смысл только при наличии хотя бы 5–7 содержательных материалов.

### Monocast
Видео и аудио: лекции, интервью, короткие монологи, подкасты и выступления. Технически это коллекция `_monocast`. Можно просто указывать внешнюю ссылку на YouTube/Instagram/Spotify — отдельный HTML не нужен.

### CV
Отдельная страница `/cv/` с образованием, текущей деятельностью, опытом работы, стажировками, исследовательским профилем и сертификатами.

## Быстрый запуск на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите в корень репозитория всё содержимое этой папки, включая `.github`.
3. Основная ветка — `main`.
4. GitHub: **Settings → Pages → Build and deployment → Source → GitHub Actions**.
5. После push workflow `.github/workflows/jekyll.yml` соберёт сайт.

После первого запуска заполните в `_config.yml`:

```yaml
url: "https://username.github.io"
baseurl: ""
```

Если сайт размещён как project site:

```yaml
url: "https://username.github.io"
baseurl: "/repository-name"
```

## Как публиковать Maqala

Создайте файл:

`_posts/YYYY-MM-DD-slug.md`

Пример:

```yaml
---
layout: post
title: "Можно ли быть свободным от результата?"
description: "Краткое описание."
series: "Один вопрос"
question: "Можно ли стремиться к цели, не становясь зависимым от результата?"
tags: ["стоицизм", "свобода", "выбор"]
---
```

Ниже пишите обычный Markdown. Шаблон лежит в `_drafts/template.md`.

## Как добавить материал в Kerek

Создайте файл, например:

`_kerek/how-to-argue.md`

```yaml
---
title: "Как разбирать аргумент"
description: "Короткое описание."
kind: "Метод"
symbol: "/"
order: 4
---
```

Далее — Markdown. Карточка автоматически появится на `/kerek/`.

## Как добавить Monocast

Создайте файл:

`_monocast/nazvanie-vypuska.md`

```yaml
---
title: "Название выпуска"
description: "Короткое описание."
format: "Видео"
symbol: "▶"
date: 2026-10-03
external_url: "https://youtube.com/..."
---
```

Если `external_url` заполнен, карточка ведёт сразу на внешнюю площадку. Если оставить его пустым, Jekyll создаст внутреннюю страницу, куда можно добавить расшифровку или заметки. Шаблон: `_drafts/monocast-template.md`.

## Что редактируется без кода

- новый текст Maqala → `_posts/`;
- новый Kerek-материал → `_kerek/`;
- новый Monocast → `_monocast/`;
- должность и ссылки → `_data/profile.yml`;
- меню → `_data/navigation.yml`;
- CV → `cv.md`.

HTML/CSS нужен только при изменении дизайна или структуры шаблонов.

## Структура

```text
_config.yml
_data/
  profile.yml
  navigation.yml
_layouts/
_includes/
_posts/                 Maqala
_kerek/                 полезные философские материалы
_monocast/              видео / аудио
_drafts/
  template.md
  monocast-template.md
assets/
maqala.html
kerek.html
monocast.html
cv.md
index.html
```

## Локальный предпросмотр (необязательно)

```bash
bundle install
bundle exec jekyll serve
```

После этого сайт будет доступен на `http://127.0.0.1:4000/`.
